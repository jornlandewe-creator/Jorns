Echte bot-replays maart 2024 – sep 2026 met alle vier modules en futures-kosten. Stijgende maand: maanden waarin BTC meer dan 5% steeg (14 keer), dalende maand: meer dan 5% daalde (9 keer). "Winst na 12 mnd": van alle mogelijke startdagen het deel dat een jaar later op winst stond. Na één maand is dat ongeveer de helft: op korte termijn is het een muntworp.
Trend-vasthouden is als enige eerst vastgelegd en daarna getest, over 2018 – sep 2026: 33% per jaar, daling −62% (BTC+ETH gewoon vasthouden: 20% per jaar, daling −88%). Sinds 2022: 25% per jaar, daling −29% (vasthouden: 3%, −69%). Veel kleine verliezen, weinig maar grote winsten. Trend snel (proef): 2018 – sep 2026 58% per jaar, daling −49%; gevonden na het bekijken van 2024-2026, dus eerst op papier volgen.
Agent (v13): dagdata 2018 – sep 2026 met dezelfde code als live: 54% per jaar, daling −27%, 2022 vlak (0%), 2018 −3%. Gekozen op 2018-2022, gecontroleerd op 2023-2026 (43% per jaar, daling −27%). Agent spot (geen hefboom): 48% per jaar, daling −24%. Agent winrate (deelwinst op +1 ATR, break-even stop): 45% per jaar, daling −24%, winrate 66%; 2023-2026: 33% per jaar. Agent long/short (futures, shorts in een bevestigde bear market): 57% per jaar, daling −30%, 2018 +21% en 2022 +22%. Geen enkele variant haalt 50% in elk jaar. Zie LEESMIJ.md.

    Instellingen

    Shorts en hefboom vragen een futures-account.
    Live haalt publieke koersen van de exchange op, zonder API key.
    Binance levert ook het aantal trades per candle, nodig voor de volume-module.
    Zet een module op 0 om hem uit te zetten. Met risicopariteit aan geldt dit alleen de eerste maand.
    Futures: rond 0,05% fee. Spot bij Bitvavo: tot 0,25%. Hogere kosten = lager rendement.
    In Telegram: zoek @BotFather, stuur /newbot, kopieer het token hierheen. Stuur daarna een berichtje naar je nieuwe bot en klik Test.
    De bot leest gratis nieuwsfeeds en vraagt Claude (goedkoopste model) alleen om nieuwe koppen te beoordelen: zo'n €0,001 per vraag, meestal minder dan €0,50 per maand. Boven het budget stopt hij vanzelf. "Beschermen": bij zeer negatief nieuws over een munt gaan de longs dicht en komen er 3 dagen geen nieuwe; bij zeer positief nieuws gaan de shorts dicht. Niet terug te testen: nieuws van vroeger is niet beschikbaar. Een Claude API key is iets anders dan je Claude-abonnement; je betaalt per gebruik.
    Elke maand gaat dit deel van de winst boven de vorige top naar een kluis. De bot handelt daar niet meer mee, dus die winst kan niet meer verloren gaan. Je kunt het van de exchange halen. Getest: kost ongeveer 10% van het eindbedrag bij 50%.
    Spot werkt bij elke gewone broker, maar zonder shorts en hefboom. Getest: 20% per jaar bij 0,05% kosten, 17% bij 0,10%, maar maar 7,5% bij 0,25% (Bitvavo). De bot handelt vaak, dus lage kosten zijn belangrijk. Geldt ook voor de backtest.
    {c} wordt de munt. OKX (ook Europa, "myokx"): {c}/USDT:USDT. Kraken futures: {c}/USD:USD. Spot bij Bitvavo of Kraken: {c}/EUR. Bestaat de notatie niet, dan zoekt de bot zelf het juiste contract (bijvoorbeeld OKX X-Perps).
    OKX vraagt bij het maken van een API key een eigen wachtwoord (passphrase). Andere exchanges: leeg laten.
    Wordt alleen op deze computer bewaard (config.json). Geef de key alleen handelsrechten, nooit opnemen.
